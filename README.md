# 🧮 Scientific Calculator

A modern, responsive and user-friendly Scientific Calculator Web Application developed using **HTML, CSS and JavaScript**.

This project performs basic arithmetic operations and advanced scientific calculations with a clean interface and easy-to-use functionality.

## 🌐 Live Demo

**[🚀 Click Here to Use Scientific Calculator](https://sehgal1001.github.io/scientific-calculator/)**

## 📌 About The Project

The Scientific Calculator is a web-based application developed as a Final Year Academic Project.

The main objective of this project is to provide users with a simple and efficient platform for performing mathematical calculations, including basic arithmetic and advanced scientific operations.

The application is designed with a responsive user interface and supports both mouse and keyboard interactions.

## ✨ Features

- Basic Arithmetic Operations
- Addition, Subtraction, Multiplication and Division
- Scientific Calculations
- Trigonometric Functions (SIN, COS, TAN)
- Logarithmic Functions (LOG, LN)
- Square Root Calculation
- Power and Square Calculations
- Factorial Calculation
- Percentage Calculation
- Pi (π) and Euler's Number (e)
- Degree (DEG) and Radian (RAD) Modes
- Calculation History
- Keyboard Support
- Clear and Delete Functions
- Responsive Design

## 🚀 Getting Started

Follow these instructions to run the project on your local computer.

### Prerequisites

- Visual Studio Code
- Google Chrome or any modern web browser
- Live Server Extension

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Sehgal1001/scientific-calculator.git
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension.

4. Right-click on `index.html`.

5. Select **Open with Live Server**.

6. The Scientific Calculator will open in your browser.

## 📖 How to Use

1. Open the Scientific Calculator in your browser.
2. Enter numbers using the calculator buttons.
3. Select the mathematical operation.
4. Press the equals (=) button to display the result.
5. Use DEG/RAD to change the angle mode.
6. Use the History button to view previous calculations.
7. Use AC to clear the current calculation.
8. Use DEL to remove the last entered character.
